# Diccionarios de corrección ortográfica

IngeCalc carga estos diccionarios Hunspell de forma diferida para la corrección
ortográfica de las regiones de texto.

| Idioma | Código | Origen | Licencia |
|---|---|---|---|
| Español | `es` | [wooorm/dictionaries](https://github.com/wooorm/dictionaries) | GPL-3.0 OR LGPL-3.0 OR MPL-1.1 |
| Inglés | `en` | [wooorm/dictionaries](https://github.com/wooorm/dictionaries) | MIT AND BSD |
| Francés | `fr` | [wooorm/dictionaries](https://github.com/wooorm/dictionaries) | MPL-2.0 |
| Árabe | `ar` | [LibreOffice/dictionaries](https://github.com/LibreOffice/dictionaries) | Ver `ar/README.txt` |
| Hindi | `hi` | [LibreOffice/dictionaries](https://github.com/LibreOffice/dictionaries) | Ver `hi/README.txt` |

Los archivos `LICENSE` y `README.txt` de cada carpeta conservan la atribución
original. El chino simplificado está disponible como idioma de interfaz, pero
no usa corrección Hunspell porque su escritura no se basa en palabras separadas
por espacios.
