# Código de conducta

## Nuestro compromiso

Como participantes y mantenedores, nos comprometemos a hacer de la comunidad de
IngeCalc un espacio libre de acoso para todas las personas, independientemente de
su edad, identidad, experiencia, nacionalidad, apariencia, religión, orientación
sexual o nivel técnico.

## Comportamiento esperado

- Usar un lenguaje respetuoso y constructivo.
- Aceptar críticas técnicas y explicar las decisiones con argumentos.
- Priorizar lo que beneficia al proyecto y a sus usuarios.
- Dar crédito al trabajo de otras personas.
- No publicar información privada sin permiso.

## Comportamiento inaceptable

- Insultos, amenazas, acoso o ataques personales.
- Comentarios discriminatorios o sexualizados.
- Publicar datos privados de terceros.
- Spam, suplantación de identidad o manipulación maliciosa.
- Cualquier conducta que un mantenedor considere razonablemente inapropiada.

## Aplicación

Los mantenedores pueden editar o eliminar comentarios, cerrar incidencias y
restringir la participación cuando se incumpla este código. Las decisiones se
tomarán de forma razonable y proporcional.

Para reportar un incidente, contacta de forma privada con los mantenedores a
través del perfil de GitHub del proyecto. No uses una incidencia pública para
reportar acoso o datos personales.

## Alcance

Este código se aplica en el repositorio, en las discusiones, en las revisiones de
código y en cualquier espacio donde alguien represente a IngeCalc.
